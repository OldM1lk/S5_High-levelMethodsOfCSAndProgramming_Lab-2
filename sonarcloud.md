# Интеграция статического анализатора
Интеграция
- Регистрация учетной записи SonarQube Cloud на сайте sonarcloud.io
- После регистрации импортировать аккаунт Github
- Установить SonarQube Cloud App в репозиторий GitHub
- Выбрать бесплатный план

Этапы анализа
- Выбрать проект
- Автоматический анализ SonarQube Cloud не требует настройки, поэтому можно начать сканирование немедленно.
- Установить New Code Definition (NCD) для проекта.
